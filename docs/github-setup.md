# Публикация и порядок сопровождения

Этот репозиторий предназначен для отдельной публичной истории. Основная ветка main; первый commit содержит только актуальную поставку, без прежней .git и личных материалов. Remote пока не настроен, push не выполнялся. История до этой поставки в публичный Git не импортируется.

После предоставления точного URL и авторизации через SSH или credential manager:

```text
git remote add origin <REPOSITORY_URL>
git remote -v
git push -u origin main
```

Не добавляйте токен в URL или .env.example. Не применяйте force push. Если выбранный remote уже содержит историю, сначала согласуйте её отдельно. После публикации сравните GitHub hash с локальным и выполните clone/install/tests по README.

Дальнейшие изменения ведутся только здесь. Предыдущий локальный репозиторий остаётся архивом, без параллельных активных ветвей и обратной синхронизации. Личные заметки ведутся вне публичного checkout; learning/ также исключён из Git и Docker context как защитная мера. Публичные инженерные ADR остаются в docs/.

Проверка корневого коммита и clone-smoke фиксируются в validation-report.md. Проверяется не только рабочее дерево, но и список/содержимое всех blobs первого commit. Маски secrets/PII дополняются просмотром файлов: regex scan не является универсальной гарантией отсутствия чувствительных данных.
