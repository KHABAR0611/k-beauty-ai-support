# Совместимость и версии данных

Инженерная версия0.3.0 сохраняла локальные исходники1.0. Версия0.3.1 намеренно корректирует их до1.1 по ADR-016: порог доставки после промокода и бонусов, совмещение разрешено, cap20% после promo, цены KB-004=1890/KB-005=1590. Остальные SKU/цены/характеристики и сроки не менялись. История сохранена, прежний snapshot не объявляется действующим.

В новой подготовленной генерации сохраняются logical UUID, обновляются source/content hashes и document_version. CURRENT переключается на полную1.1; прежняя локальная генерация остаётся доступной для аудита. Embedding-ready не заявляется, Qdrant business publishing не выполняется.
