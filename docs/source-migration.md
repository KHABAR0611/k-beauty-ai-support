# Source compatibility

Версия 0.3.0 сохраняет три исходных файла, 9 SKU, цены и характеристики, DR/PL IDs, пороги, сроки и правила расчётов. Бизнес-политики остаются версии 1.0. Изменения инженерных компонентов не меняют бизнес-правила.

Экспорт не заменяет источники: исходные byte hashes сохраняются в manifest. Snapshot каталога канонизирует JSON без потери полей и точности чисел. Для изменений данных новое поколение включает полный актуальный набор, поэтому удалённые товары не остаются в активном export.
