Источники, проверены2026-10-20: [Ollama Qwen3](https://ollama.com/library/qwen3:0.6b), [local structured outputs](https://docs.ollama.com/capabilities/structured-outputs), [Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing), [Gemini structured outputs](https://ai.google.dev/gemini-api/docs/structured-output), [Groq models](https://console.groq.com/docs/models), [Groq structured outputs](https://console.groq.com/docs/structured-outputs). Тарифы могут меняться. Преимущество по качеству русского не объявляется без одинаковой оценки.

Решение: реализовать проверяемый локальный Ollama adapter и Provider protocol; production configuration по умолчанию disabled. Платные подключения и расходы не разрешены, поэтому облачные провайдеры не подключаются. Test doubles доступны только через dependency injection в тестах, не как runtime provider. Без LLM полная readiness503, FAQ chat503; typed tools и capability control работают без модели. Затем выполнен реальный локальный прогон12 сценариев без doubles:8 tools,2 control,2 LLM, плюс LLM injection. Фактические tokens/latency и ограничения опубликованы в block-5-results.md. Превосходство над облачными кандидатами не заявляется.

Первый generation contract намеренно extractive: модель выбирает evidence units, а сервер проверяет ID/полноту исходного абзаца и рендерит утверждения только из разрешённых полных фрагментов. Произвольный парафраз не объявляется проверенным по наличию citation. Денежные результаты вычисляются отдельным versioned Decimal-инструментом; недостающие входы вызывают уточнение. Это ограничивает выразительность, но делает поддержку утверждений проверяемой без второго непроверенного judge-LLM.
